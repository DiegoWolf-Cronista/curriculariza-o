Linguagens usadas: Foram utilizados como linguagens principais:

  HTML: Usado para a construção do que foi escrito e no posicionamento dos textos.  
  
  JavaScript: Usado para possibilitar uma melhor organização da lógica do aparecimento das perguntas, e principalmente para 
  permitir o uso de funções, com isso o projeto pode ter funcionalidades que o HTML e o CSS sozinhos não poderiam proporcionar
  
  CSS: Incluido no projeto para permitir um melhor estilo, cores, posicionamento e etc.
